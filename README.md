## How I build

- 先从真实问题出发，再决定是否需要模型、Agent 或更复杂的系统。
- 让数据、模型、工程和产品交互形成完整闭环，而不是只追求单点 Demo。
- 优先做简单、可解释、可维护的方案；复杂度应该服务于结果。
- 只公开经过验证和脱敏的技术内容。
