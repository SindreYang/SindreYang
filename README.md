## Engineering principles

- 先解决真实用户问题，再选择合适的模型和工程方案。
- 简单判断不滥用大模型，复杂任务才使用上下文和 Agent 编排。
- 从数据、模型、后处理、服务、部署到产品交互，建立完整闭环。
- 保护公司和客户数据，只公开可验证、可脱敏的技术内容。
